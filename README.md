# IDVC-FRONT
Esta es una aplicación pequeña y ligera para la validación de certificados. 
El cual su proposito es mostrar el diseño del verificador de certificados para la empresa CAENE (Centro de Altos Estudios de Negocio y Economía)
- Cuando se va a manipular el codigo se recomienda siempre dejar un comentario para guiarse
- Para modificar el diseño o estilo se recomienda siempre separar el CSS del HTML

REQUISITOS
- Instalar visual code
- Instalar git para editar la terminal del visual code
- Instalar Node js
- Instalar una versión compatible de angular 16 o 17

INSTALACIÓN Y DESPLEGAR FRONT
- npm install -g @angular/cli
- npm install (Para ejecucion del programa)
- ng serve
